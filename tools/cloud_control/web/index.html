ЛОКАЛЬНАЯ КОНФИГУРАЦИЯ

Подключение к AWS

Номер аккаунта и профиль доступа. Секретные ключи не вводятся в панель.

Как подключить аккаунт

Войдите в AWS под своей почтой. Номер аккаунта из 12 цифр находится в меню аккаунта в правом верхнем углу консоли; адрес почты вместо него не подходит.

Для профиля IAM Identity Center выполните на компьютере:

aws configure sso --profile fll-prod
aws sso login --profile fll-prod

Для обычного IAM-профиля используйте существующую настройку AWS SDK. Профиль для просмотра требует только чтения; запуск деплоя потребует отдельных прав CDK. AWS bootstrap выполняется отдельно.

Проект AWS

Создайте этого пользователя вручную в Cognito после деплоя. Пароль в панель не вводится. Модель: Qwen3 235B · Стокгольм.

Cognito access token отдельного prod-аккаунта хранится только в файле с правами 600. Он не отправляется в браузер и не записывается в отчёты. Не используйте refresh token или AWS access key.

Второй этап: параметры Apple и файлы политики

Публичные идентификаторы Apple, ARN секретов, пути к DER-сертификатам и проверенной политике. Для просмотра AWS заполнять их не обязательно. Пример: tools/cloud_control/config.example.json. Не вставляйте содержимое секретов.

Сохраняется локально в .cloud-control/config.json
