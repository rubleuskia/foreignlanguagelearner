# Экзамены: данные, локальный API и приложение

Облачный слой, административный импорт и порядок независимой публикации данных описаны
в [EXAM_AWS_IMPORT.md](EXAM_AWS_IMPORT.md). Реальные профили и пакеты хранятся вне Git,
в `/Users/arublevsky/dev/ExamSources`; тесты используют искусственные примеры.

Первый комплект — взрослый B1, 22–23 июня 2024. Импорт сохраняет все исходные
разделы, примеры, ключи, правила частичного балла, физические страницы PDF и SHA-256
оригиналов. Приложение показывает слушание, чтение и грамматику; письменная часть
остаётся в JSON, устные задания не выдумываются.

## Артефакты

Архив оригиналов находится в `/Users/arublevsky/dev/ExamSources/originals/`.
Проверенный пакет — `ExamSources/generated/pl-b1-2024-06-adults-v1/`:

- `exam.json`, `audio.json`, `exam.schema.json` — данные импорта и схема;
- `sources/` — неизменённые PDF/MP3;
- `evidence/`, `alignment/` — страницы, извлечённый текст, разметка и проверки;
- `ai-assessment.json` — ключи, промпты и строгий формат результата;
- `artifact-manifest.json` — размеры, SHA-256 и связь каждого артефакта с оригиналами;
- `web/` — автономный интерфейс эмулятора. AI в нём остаётся заглушкой.

Каноническая revision связывает содержание экзамена и аудио; digest транспортного
пакета дополнительно учитывает файлы поставки. Исправление ключа создаёт новую
revision. Перепаковка отчёта не перепривязывает старые попытки к новым вопросам.

## Импорт и локальный запуск

Установить зависимости в отдельное Python-окружение:

```sh
python3 -m venv /private/tmp/exam-venv
/private/tmp/exam-venv/bin/python -m pip install -r tools/exam-digitizer/requirements.txt
```

Импорт проверяет схему, идентификаторы, страницы, баллы, исходники, артефакты и
revision, подготавливает отдельную копию и атомарно публикует её в каталоге:

```sh
/private/tmp/exam-venv/bin/python scripts/exam-pilot.py \
  --storage-root /Users/arublevsky/dev/ExamSources/backend-pilot import \
  /Users/arublevsky/dev/ExamSources/generated/pl-b1-2024-06-adults-v1
/private/tmp/exam-venv/bin/python scripts/exam-pilot.py \
  --storage-root /Users/arublevsky/dev/ExamSources/backend-pilot serve --port 8774
```

Для раздельных dry-run/commit используется `python -m backend.exams.cli --help`.
Хранилище — SQLite с транзакциями/WAL и неизменяемые файлы ревизий в явно указанной
постоянной папке. Нет неявного хранения пользовательских данных в `/tmp`.
Локальный сервер слушает только `127.0.0.1`. Токен создаётся в `.local-api-token`
с правами 0600 и не печатается. Материалы для активного прохождения не содержат
ключей, рубрик или PDF ключей. Аудио поддерживает HTTP Range.

После Debug-сборки приложение можно подключить к этому API:

```sh
/private/tmp/exam-venv/bin/python scripts/exam-pilot.py \
  --storage-root /Users/arublevsky/dev/ExamSources/backend-pilot launch-simulator \
  --device SIMULATOR_UUID --app /absolute/path/ForeignLanguageLearner.app
```

Скрипт устанавливает приложение в указанный симулятор и передаёт локальный токен
через окружение. Такой способ подключения доступен только в Debug и только для
loopback HTTP. Обычная сборка использует существующую авторизацию приложения.

## Прохождение и синхронизация

Сессия библиотеки защищена Keychain и доступна только на разблокированном устройстве.
Фоновый таймер экзамена не опрашивает Keychain; синхронизация при закрытых защищённых
данных откладывается, локальное сохранение и обработка дедлайна продолжаются.
Временная ошибка чтения не стирает загруженный экзамен или ответы; редактирование
приостанавливается до проверки сессии. После восстановления доступа ошибка снимается
и синхронизация повторяется. Настоящий выход очищает данные владельца в памяти;
сохранённые файлы остаются разделены по сессиям. Диагностика Keychain пишет операцию
и OSStatus в системный журнал без токенов. Исправление доставляется новой iOS-сборкой.

Каталог сгруппирован по уровню CEFR и аудитории (взрослые / дети и подростки),
свежие сессии идут первыми внутри группы. Поиск учитывает название, уровень и сессию.
Слушание показывает одно задание с вкладками прогресса и переходами назад/вперёд.
При смене задания тренировочная запись останавливается; экзаменационная продолжается.

Для первого по хронологии B1 (30–31 января 2021, взрослые) подготовлена отдельная
интерактивная редакция слушания: выбор a/b/c, транспорт и описания, TAK/NIE,
говорящие с исходным числом ответов и фотографии A–K с выбором номера текста.
Целые страницы заменены структурированными вопросами; фотографии сохранены как
точные фрагменты оригинала. `blocks[].image_region` — нормализованные x/y/ширина/высота
от верхнего левого угла страницы, `item_id` связывает фотографию с вопросом.
`image_page_size` сохраняет пропорции в веб-превью. Сервер передаёт публичные ограничения
`input.format`, `slot_count`, `max_tokens`, сохраняя ключи только для оценивания.
Реальные данные остаются вне Git. Пакеты публикуются отдельно от кода;
прежние ревизии и попытки сохраняются. Другие экзамены требуют отдельной оцифровки.

20 ноября 2026 пакет `generated/pl-b1-2021-01-adults-interactive-v1` опубликован в AWS
и выбран единственной активной редакцией каталога (revision начинается с `07d655fa`).
Backend `.289` передаёт приложению фрагменты иллюстраций и ограничения ответов.
Старые попытки используют прежние данные; для новой редакции нужно обновить каталог,
открыть экзамен заново и начать новую попытку. Это обновление только слушания:
чтение и грамматика январского экзамена пока сохраняют прежнее представление.

Отдельная вкладка «Экзамены» содержит каталог, разделы и сохранённые попытки.
Режим выбирается до начала. В тренировке доступны проигрыватели участков заданий;
в экзамене проигрывается цельный оригинал один раз, без ручной паузы/перемотки.
Прерывание сохраняет позицию; продолжение не создаёт новую попытку.

Ответы и очередь изменений сохраняются одной локальной операцией. Сервер проверяет
владельца, revision, версии и идентификаторы изменений. Повтор изменения идемпотентен.
Конфликты не удаляют локальные ответы; интерфейс позволяет сравнить серверную версию
и экспортировать локальный черновик. Передача активного аудио другому устройству
требует явного подтверждения с актуальной версией попытки.

Чтение и грамматика в экзаменационном режиме сдаются по сохранённому дедлайну,
включая время вне приложения. Сервер не принимает позднее изменение сданного
раздела. Если устройство было без сети и его ответы впервые поступили после
дедлайна, они сохраняются локально как конфликтующий черновик; сервер не выдаёт
непроверяемое клиентское время за доказательство своевременной сдачи.

Объективные баллы считаются по серверным ключам. Числовые ответы слушания V дают
частичный балл за уникальные правильные числа в пределах числа ответов задания.
При ожидающей AI-проверке итог не подменяется нулём; известные баллы показываются
отдельно от окончательного результата.

## AI-проверка грамматики V/VI

Приложение использует `TranslationRequestSettings`, тот же Keychain/HTTP-клиент
и подписочный журнал запросов, что переводы. После сдачи сервер выдаёт материал
только нужного задания с официальным ключом и исходными правилами.

В режиме личного ключа запрос идёт напрямую в Responses API, результат сохраняется
с происхождением `client_personal_key`. Запись отправки сохраняется до POST:
после неизвестного исхода повторный платный вызов автоматически не выполняется.
В подписочном режиме сервер сам загружает рубрику, использует существующую очередь,
лимиты, idempotency и восстановление результата. Клиент не передаёт свою рубрику.

Результат строго содержит `score_units` и `rationale`: целые сотые балла, шаг 25,
предел задания и непустая мотивировка. Отказ, незавершённый ответ или ошибочная
структура не превращаются в нулевую оценку. Неоднозначность оригинального ключа
V-4 сохраняется. Живые вызовы модели и качество AI-оценивания требуют отдельной
проверки; структурные тесты не подтверждают качество оценки.

## Границы текущей поставки

Локальный API и импорт работают на постоянном файловом хранилище. Код маршрутов
подключён к существующим серверным проверкам доступа, но новые облачные ресурсы,
маршруты API Gateway и постоянное облачное хранилище экзаменов не развёрнуты.
Продакшен-загрузка больших MP3 требует согласованного хранилища/выдачи файлов;
большой файл не следует возвращать обычным JSON-ответом функции.

Аудио сохраняет `requires_listening_review`: успешный aligner не заменяет проверку
слухом, в частности повтора III и отмеченных слов. Импорт не скрывает эти признаки.

Детальные требования: [план](EXAM_IMPLEMENTATION_PLAN.md).
