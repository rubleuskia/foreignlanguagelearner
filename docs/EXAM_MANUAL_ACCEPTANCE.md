# Ручная проверка экзаменов на iPhone

20 ноября 2026 проверен живой operator API: вход по свежей сессии, каталог без
отложенных экзаменов, выдача без ключей, скачивание PDF/MP3 с проверкой SHA-256,
попытка по чтению, сохранение/повтор изменения, конфликт устаревшей версии,
перехват другим устройством и сохранённый результат после сдачи. Отчёт хранится
внешне в `ExamSources/publications/authenticated-api-acceptance-20261120.json`.
Это не проверка интерфейса iPhone, качества AI или прослушивание записей.
Проверки на симуляторе не выполнять по указанию пользователя.

Ниже остаются случаи, которые требуют ручной проверки. Использовать отдельные
тестовые попытки; результаты пользователя не изменять.

| Сомнительный случай | Как проверить вручную | Ожидаемое поведение |
| --- | --- | --- |
| Вход и обновление сессии | На iPhone войти в библиотеку через настройки, открыть экзамены. Оставить приложение в фоне до истечения access token и вернуться. Затем выйти и войти заново. | Каталог открывается после входа; действующий refresh token восстанавливает сессию. После выхода требуется новый вход, нет бесконечного индикатора загрузки. |
| Разные уровни и возрастные группы | Открыть по одному B1/B2/C1/C2 и молодёжному экзамену. Сравнить экран задания с исходной страницей PDF: пример, таблицу, банк слов, подписи и число полей. | Все исходные варианты и поля доступны; примеры не становятся дополнительными оцениваемыми ответами; письмо/говорение не запускаются как активный экзамен. |
| Начала, окончания и повторы аудио | В тренировке прослушать первые и последние 10–15 секунд каждого отрывка; сравнить с полной MP3. Отдельно проверить длинный C2, задание с примером и повторные чтения. | Не потеряны первые/последние слова и пример; не захвачен соседний фрагмент. Число чтений соответствует оригиналу. Числа и произнесённые заголовки сохранены; машинный флаг не выдаётся за ручное одобрение. |
| Большие файлы и обрыв загрузки | Начать скачивание аудио, включить авиарежим, вернуть сеть и повторить. Закрыть приложение во время скачивания и открыть снова. Проверить PDF и воспроизведение после завершения. | Незавершённый файл не считается готовым; повтор доступен, размер/хеш проверены, нет повреждённого воспроизведения и потери ответов. |
| Ответы без сети и закрытие приложения | Начать попытку, отключить сеть, заполнить несколько разных полей, полностью закрыть приложение и открыть снова. Вернуть сеть. | Черновик восстанавливается и синхронизируется; поля и текущий раздел не исчезают. Ошибка сохранения видна, окончательно отвергнутый черновик доступен для восстановления. |
| Два устройства и устаревшая версия | Открыть одну тестовую попытку на двух iPhone. На первом изменить ответ, на втором попробовать сохранить старую версию и явно перехватить попытку. | Конфликт показан пользователю; старый ответ не перезаписывает новый молча. После подтверждённого перехвата сохранённые ответы остаются. Повтор сдачи не создаёт вторую попытку. |
| Закреплённая версия материалов | Начать попытку, затем открыть её после публикации новой версии того же экзамена. | Попытка продолжает использовать свою исходную revision и материалы; ответы не применяются к изменённым заданиям. Новая попытка получает текущую версию. |
| Таймер в фоне и часы устройства | В режиме экзамена начать чтение/грамматику, свернуть приложение и вернуться после реального срока раздела. Изменить часы телефона; отдельно сравнить тренировочный режим. | Решение о сроке принимает сервер. Смена часов и фон не продлевают экзамен; поздний ответ не меняет сданный раздел. Тренировка не получает экзаменационный таймер. Не сокращать производственные сроки ради теста. |
| Частичный ответ и связанные поля | В тестовой попытке проверить ответ с несколькими допустимыми токенами, неполный ответ, лишний вариант и связанную пару полей с неоднозначным официальным ключом. Сверить результат с PDF-ключом. | Учитываются исходные правила частичного балла; лишние токены не повышают результат. Неопределённая ручная проверка остаётся pending, не превращается в автоматически выставленный ноль или придуманное правило. |
| AI вместе с ручной проверкой | Сдать раздел со свободным ответом и вручную проверяемым полем. Выполнить один AI-запрос и сравнить объяснение с официальной рубрикой; повторно открыть результат. | AI-оценка относится к нужному заданию и версии, сохраняется после открытия. Ручное поле остаётся pending даже после получения AI-ответа; интерфейс не объявляет весь раздел окончательно оценённым. Объективный API-тест этого не подтверждает. |
| Ошибка AI и повтор | Во время одного тестового AI-запроса прервать сеть, восстановить её и заново открыть попытку. | Сохранённый результат восстанавливается; неизвестный исход не вызывает молчаливый повтор платной операции. Понятны доступные действия и оставшиеся pending-поля. |
| Полностью отложенный экзамен | Сверить каталог с внешним `ExamSources/deferred/index.json`; проверить поиск и фильтры. | Ни один целиком отложенный экзамен не доступен, включая его чтение и грамматику. Незавершённые пакеты не публикуются для обхода аудиопроверки. |

Для каждого случая записать модель iPhone, версию сборки, exam ID/revision,
ID тестовой попытки, шаги и фактический результат. Для аудиозамечания добавить
задание/чтение и время в полной исходной MP3. Не включать пароли, токены,
подписанные ссылки или полные экзаменационные материалы в Git и отчёт PR.
