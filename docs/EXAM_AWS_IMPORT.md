# Импорт оцифрованных экзаменов в AWS

Код и материалы выпускаются независимо. В Git находятся приложение, API, инфраструктура,
схема, утилиты и искусственные тестовые примеры. Реальные профили, JSON-пакеты, PDF,
ключи, MP3, отчёты и квитанции публикации остаются в `/Users/arublevsky/dev/ExamSources`.
Ранее отслеживаемый пилотный профиль удалён из текущего дерева; история Git не переписывается.

## Состояние и условия запуска

Этот PR реализует облачное хранение, но сам по себе ничего не развёртывает и не загружает.
Ранее выпущенный backend `.273` ещё не содержит ресурсы облачных экзаменов.
До загрузки необходимо слить PR, дождаться проверенного backend-тега и развернуть его
обычным процессом Cloud Control. Не использовать локальный SQLite или диск Lambda
для производственных попыток. В AWS экзамены этим изменением пока не опубликованы.

Используется выбранный Region `eu-north-1`. Для каждого окружения инфраструктура выдаёт
выходы `ExamsTableName` и `ExamsBucketName`; фактические логические имена выходов видны
в шаблоне стека. Operator и subscription — отдельные окружения с отдельными ресурсами
и пользователями. Публикацию выполняют отдельно в целевое окружение, не копируя попытки
между ними. Профиль AWS должен давать доступ к выбранному проекту.

## Что и где хранится

| Место | Данные |
|---|---|
| Закрытый versioned S3 | Полный пакет, включая оригиналы и ключи; каждый объект привязан к S3 VersionId, размеру и SHA-256 |
| `exams/<exam_id>/<revision>/<manifest_digest>/…` | Неизменяемый префикс конкретного содержимого и упаковки |
| DynamoDB `EXAM#<id>` / `REV#<revision>` | Ссылки на проверенные версии объектов и разрешённые публичные материалы |
| DynamoDB `CATALOG` / `EXAM#<id>` | Указатель на опубликованную версию и небольшая карточка каталога |
| DynamoDB `OWNER#<sha256(auth_owner)>` | Попытки, обработанные изменения и квитанции административных транзакций |

Таблица защищена от удаления, имеет PITR и `RETAIN`. Bucket закрыт для публичного доступа,
использует HTTPS, шифрование и версионирование, сохраняется при удалении стека.
JSON с текстами и ключами не кладётся целиком в DynamoDB. Записи состояния ограничены
350 KiB в UTF-8, чтобы не упираться в предел размера элемента. Слишком большой черновик
не обрезается: сервер возвращает явную ошибку, клиент сохраняет локальную копию.

## Проверка без подключения к AWS

Из корня репозитория, в Python-окружении с зависимостями backend:

```sh
python -m backend.exams.cloud_cli dry-run \
  /Users/arublevsky/dev/ExamSources/generated/pl-b1-2024-06-adults-v2
```

Эта команда не создаёт AWS-клиентов и не пишет в S3 или БД. Она проверяет JSON Schema,
исходные URL/страницы/хеши, все файлы манифеста, размеры, отсутствие обхода каталогов
и symlink, суммы баллов, ссылки на варианты, правила частичного ответа, AI-контракты,
аудио-границы и каноническую `revision`. Возвращает `manifest_digest`, `revision`
и число разделов/заданий/полей. Акустические и редакционные замечания сохраняются;
успех проверки формата не означает прослушивание человеком или проверку качества AI.

## Публикация

После развёртывания задать реальные выходы целевого стека и значения из dry-run.
`TRANSACTION_ID` — один UUID для одной попытки публикации; при повторе после обрыва
использовать тот же UUID и тот же `manifest_digest`.

```sh
python -m backend.exams.cloud_cli \
  --profile default --region eu-north-1 \
  --table "$EXAMS_TABLE" --bucket "$EXAMS_BUCKET" \
  commit /Users/arublevsky/dev/ExamSources/generated/pl-b1-2024-06-adults-v2 \
  --transaction-id "$TRANSACTION_ID" \
  --manifest-digest "$MANIFEST_DIGEST" \
  --report /Users/arublevsky/dev/ExamSources/publications/pilot-aws-receipt.json
```

1. Повторно проверить весь локальный пакет и совпадение ожидаемого манифеста.
2. Загрузить объекты с `If-None-Match: *` и явной SHA-256 checksum. Существующий объект
   принимается только после проверки размера, checksum и ненулевого VersionId.
3. Сохранить для каждого объекта конкретный VersionId. Повторно проверить локальные
   файлы после загрузки, чтобы заметить изменение исходника во время публикации.
4. Одной транзакцией DynamoDB записать новую ревизию, указатель каталога и квитанцию
   операции. Условия записи предотвращают перезапись чужого изменения при конкуренции.
5. Записать локальную квитанцию в `ExamSources/publications`. Она содержит результат,
   идентификатор транзакции и версию, но не токены и не AWS credentials.

Незавершённые загрузки не видны в каталоге. Повтор с тем же UUID безопасен; тот же UUID
с другим манифестом отклоняется. Повторная упаковка уже известной ревизии не переключает
каталог назад. Новая опубликованная ревизия не меняет исходник существующих попыток:
они закреплены за своей `revision` и VersionId. Автоматического удаления старых версий
или неиспользованных загрузок нет; очистка — отдельная операция.

## Проверка результата и работа приложения

```sh
python -m backend.exams.cloud_cli \
  --profile default --region eu-north-1 \
  --table "$EXAMS_TABLE" --bucket "$EXAMS_BUCKET" catalog
```

После публикации необходимо отдельно проверить авторизованный сценарий приложения:
каталог → версия без ключей → скачивание PDF/MP3 → создание попытки → ответ → повтор
того же изменения → конфликт двух устройств → сдача/истечение времени → результат.
Локальные тесты с Moto проверяют эти механизмы, но не заменяют проверку развёрнутого API.

API получает владельца из проверенной сессии, никогда из тела запроса. Выдаёт student
projection без ключей, рубрик и приватного текста аудио. Временная ссылка S3 выдаётся
только для `paper` и `audio`, действует 900 секунд и закреплена за VersionId. iOS
скачивает её без API bearer-токена, проверяет допустимый адрес, размер и SHA-256.
При истечении ссылки следует запросить новую метаинформацию, а не менять подпись URL.

Ответы сохраняются на устройстве и синхронизируются через версию и change_id.
Сервер повторно считает объективные баллы и сроки; клиентский результат не считается
истиной. Частичные ответы проверяются по исходному алфавиту/количеству слотов.
Свободные ответы после сдачи идут через существующий AI-маршрут переводов; строгий
ответ содержит `score_units` и `rationale`. Письменная часть остаётся в JSON и не запускается.

## Доступ администратора и runtime

Импорт не открыт обычному приложению: облачные HTTP-импорты отклоняются, административных
маршрутов публикации нет. Утилита использует AWS SDK и текущую AWS-сессию администратора.
Runtime получает `EXAMS_TABLE` и `EXAMS_BUCKET`; конфликтующие/неполные настройки дают
ошибку, а не переключаются на временную локальную БД.

Lambda нужен доступ чтения/записи состояния DynamoDB и `s3:GetObject`/`s3:GetObjectVersion`
в `exams/*`; загрузку объектов выполняет только административный процесс с `s3:PutObject`.
Секреты и токены не записываются ни в пакет, ни в Git, ни в квитанцию публикации.
